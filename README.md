# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 贯验孤儿卫星 · 乙口径（当前+历史链）

全局只贯彻一种口径：**同父下任一卫星行（当前或历史非当前）父不可解即孤儿，本轮贯验失败**。
「仅历史孤儿、无当前孤儿」同样判失败；死父键在清理/重挂并重新贯验通过前禁止再开新当前版。

- 扫描：`GET /api/孤儿`、`GET /api/卫星/巡检`、`GET /api/卫星/孤儿`
- 履历：`GET /api/贯验/孤儿`（末次或 `?贯验编号=`）
- 开版闸：`POST /api/卫星/开版`，失败闭、零增量；装载链路共用同一闸
- 夹具：`孤儿-当前`、`孤儿-历史`、`孤儿-失败后开版`（`POST /api/夹具/场景?名=...`）
- 自检：`python3 backend/scripts/孤儿场景自检.py`
